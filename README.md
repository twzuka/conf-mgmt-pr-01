# Конфигурационное управление — практическая работа № 1

**Группа:** ИКБО-40-25  
**Вариант:** 13

## 1. Общее описание

Эмулятор языка оболочки UNIX-подобной ОС с консольным интерфейсом.
Приложение написано на Python 3.9+ и не требует сторонних библиотек.

Сейчас реализованы этапы 1 и 2:

- приглашение на основе имени пользователя, компьютера и текущего каталога;
- простой разбор команды и аргументов по пробелам;
- команды-заглушки `ls` и `cd`;
- команда `exit` и сообщение для неизвестной команды;
- параметры командной строки для VFS, приглашения и стартового скрипта;
- отладочный вывод всех параметров при запуске;
- последовательное выполнение команд стартового скрипта.

Путь к VFS на этапе 2 только принимается и выводится. Чтение XML-файла
VFS и проверка ошибок его загрузки относятся к этапу 3. Команды `ls` и
`cd` пока остаются заглушками до этапа 4.

## 2. Описание функций и настроек

### Параметры командной строки

Все параметры необязательны.

| Параметр | Назначение |
|---|---|
| `--vfs-path PATH` | Путь к физическому расположению VFS |
| `--prompt TEXT` | Пользовательское приглашение к вводу |
| `--script PATH` | Путь к стартовому скрипту |

Без `--prompt` формируется приглашение вида
`username@hostname:current_directory$ `. Без `--script` сразу запускается
интерактивный REPL.

При запуске программа печатает значения всех трёх параметров. Для
параметров, которые не были заданы, выводится `None`.

### Стартовый скрипт

Стартовый скрипт — обычный текстовый файл в кодировке UTF-8. В каждой
строке находится одна команда эмулятора. Перед результатом программа
печатает приглашение и саму строку, имитируя интерактивный диалог.

Пустые строки пропускаются. Неизвестная команда выводит сообщение об
ошибке, после чего выполняется следующая строка. Если файл невозможно
прочитать, выводится сообщение `Startup script error: ...`, затем
запускается REPL. Команда `exit` завершает весь эмулятор.

### Команды эмулятора

| Команда | Поведение на этапе 2 |
|---|---|
| `ls` | Заглушка: печатает имя команды и список аргументов |
| `cd` | Заглушка: печатает имя команды и список аргументов |
| `exit` | Завершает работу эмулятора |

Любая другая команда приводит к сообщению
`<команда>: command not found`, после чего работа продолжается.

В интерактивном режиме `Ctrl+D` завершает работу, а `Ctrl+C` сбрасывает
текущую строку ввода.

### Основные функции (`src/main.py`)

| Функция | Назначение |
|---|---|
| `create_argument_parser()` | Создаёт описание параметров CLI |
| `parse_arguments(arguments)` | Разбирает параметры командной строки |
| `print_configuration(config)` | Печатает значения трёх настроек |
| `get_username()` | Возвращает имя пользователя ОС |
| `get_hostname()` | Возвращает имя компьютера |
| `get_current_dir()` | Возвращает текущий каталог для приглашения |
| `get_prompt(custom_prompt)` | Выбирает пользовательское или обычное приглашение |
| `parse_command(line)` | Делит строку на команду и аргументы |
| `print_stub(name, args)` | Печатает имя и аргументы команды-заглушки |
| `command_ls(args)` | Заглушка команды `ls` |
| `command_cd(args)` | Заглушка команды `cd` |
| `execute_command(name, args)` | Выполняет найденную команду |
| `execute_line(line)` | Разбирает и выполняет одну строку |
| `run_startup_script(path, prompt)` | Выполняет стартовый скрипт |
| `run_repl(prompt)` | Запускает интерактивный цикл |
| `main(arguments)` | Настраивает и запускает эмулятор |

## 3. Сборка, запуск и тесты

Сборка не требуется. Из корня репозитория выполните:

```text
python src/main.py
```

Пример запуска со всеми параметрами:

```text
python src/main.py --vfs-path vfs.xml --prompt "demo> " --script scripts/startup.txt
```

Краткая справка по параметрам:

```text
python src/main.py --help
```

Запуск через системные скрипты:

```text
run.bat
sh run.sh
```

Файл `run.sh` хранится без права выполнения, поэтому после клонирования
его можно запускать командой `sh run.sh`. Другой вариант — один раз
выдать право выполнения командой `chmod +x run.sh`.

Проверка всех параметров по отдельности и вместе:

```text
scripts\check_parameters.bat
sh scripts/check_parameters.sh
```

Запуск unit-тестов:

```text
python -m unittest discover -s tests
```

## 4. Примеры использования

Интерактивный запуск с пользовательским приглашением:

```text
> python src/main.py --vfs-path vfs.xml --prompt "demo> "
Configuration:
  VFS path: vfs.xml
  Prompt: demo>
  Startup script: None
demo> ls one.txt
Command: ls
Arguments: ['one.txt']
demo> exit
```

Файл `scripts/startup.txt` специально содержит ошибочную команду.
Следующая команда после неё всё равно выполняется:

```text
> python src/main.py --prompt "demo> " --script scripts/startup.txt
Configuration:
  VFS path: None
  Prompt: demo>
  Startup script: scripts/startup.txt
demo> ls one.txt
Command: ls
Arguments: ['one.txt']
demo> unknown_command
unknown_command: command not found
demo> cd documents
Command: cd
Arguments: ['documents']
demo> ls -l
Command: ls
Arguments: ['-l']
demo> exit
```

# Конфигурационное управление — практическая работа № 1

**Группа:** ИКБО-40-25  
**Вариант:** 13

## 1. Общее описание

Эмулятор языка оболочки UNIX-подобной ОС с консольным интерфейсом (CLI).
Приложение написано на Python 3.9+ и не требует сторонних библиотек.

Работа выполняется поэтапно. Сейчас реализован **этап 1 (REPL)** —
минимальный прототип, в котором диалог с пользователем уже работает,
а большинство команд являются заглушками.

Что умеет прототип:

- показывает приглашение к вводу, построенное на реальных данных ОС
  (имя пользователя, имя компьютера, текущий каталог);
- разбивает введённую строку на команду и аргументы по пробелам;
- выполняет команды-заглушки `ls` и `cd`, которые печатают своё имя
  и аргументы;
- завершает работу по команде `exit`;
- сообщает об ошибке при вводе неизвестной команды.

## 2. Описание функций и настроек

### Настройки

На этапе 1 пользовательских настроек (параметров командной строки,
конфигурационных файлов) нет.

### Команды эмулятора

| Команда | Поведение на этапе 1                                     |
|---------|----------------------------------------------------------|
| `ls`    | Заглушка: печатает имя команды и список аргументов       |
| `cd`    | Заглушка: печатает имя команды и список аргументов       |
| `exit`  | Завершает работу эмулятора                               |

Любая другая команда приводит к сообщению
`<команда>: command not found`, после чего работа продолжается.
Пустая строка (или строка из одних пробелов) игнорируется.

Горячие клавиши: `Ctrl+D` завершает работу, `Ctrl+C` сбрасывает
текущую строку ввода.

### Функции (`src/main.py`)

| Функция                     | Назначение                                                     |
|-----------------------------|----------------------------------------------------------------|
| `get_username()`            | Имя текущего пользователя ОС (запасное значение — `user`)      |
| `get_hostname()`            | Имя компьютера                                                 |
| `get_current_dir()`         | Текущий каталог; домашний каталог показывается как `~`         |
| `get_prompt()`              | Собирает приглашение вида `username@hostname:~$ `              |
| `parse_command(line)`       | Делит строку на команду и список аргументов по пробелам        |
| `print_stub(name, args)`    | Печатает имя команды-заглушки и её аргументы                   |
| `command_ls(args)`          | Заглушка `ls`                                                  |
| `command_cd(args)`          | Заглушка `cd`                                                  |
| `execute_command(name, args)` | Выполняет команду; возвращает `False`, если нужно выйти      |
| `run_repl()`                | Цикл «чтение — выполнение — вывод»                             |
| `main()`                    | Точка входа                                                    |

## 3. Сборка, запуск и тесты

Сборка не требуется, нужен только установленный Python 3.9 или новее.

Запуск (из корня репозитория):

```
python src/main.py
```

Запуск через скрипт:

```
run.bat        # Windows
./run.sh       # Linux / macOS
```

Запуск тестов:

```
python -m unittest discover -s tests
```

## 4. Примеры использования

Имя пользователя и имя компьютера в приглашении зависят от вашей ОС.

```
username@hostname:~$ ls
Command: ls
Arguments: []
username@hostname:~$ ls -l test.txt hello.txt
Command: ls
Arguments: ['-l', 'test.txt', 'hello.txt']
username@hostname:~$ cd documents
Command: cd
Arguments: ['documents']
username@hostname:~$ unknown_cmd
unknown_cmd: command not found
username@hostname:~$ 
username@hostname:~$ cd
Command: cd
Arguments: []
username@hostname:~$ exit
```
